## 2024-05-18 - Missing labels in design systems\n**Learning:** When adopting minimal design systems (like Hyper-WIMP) that intentionally omit explicit HTML `<label>` elements to save space, screen reader accessibility is often compromised. These designs rely heavily on visual layout and placeholder text to convey meaning.\n**Action:** Always map backend template variables (e.g., `data_item.prompt` or `data_item.name`) to the `aria-label` attribute on dynamically generated inputs to ensure the necessary context is preserved for assistive technologies without disrupting the visual aesthetic.
