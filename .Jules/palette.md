## 2024-04-11 - Dynamic ARIA Labeling in Hyper-WIMP Interfaces
**Learning:** In highly customized, Cyberpunk-themed UIs (like the Hyper-WIMP command palette) where explicit `<label>` elements are omitted for aesthetic reasons, dynamic `<input>` and `<textarea>` elements mapped from server-driven generic JSON schemas lack accessible names. Relying solely on `placeholder` text is insufficient for robust screen reader support.
**Action:** When designing templates that render arbitrary data points or template forms without explicit `<label>` tags, dynamically map the `data_item.prompt` (or fallback to `data_item.name`) directly to the `aria-label` attribute on the corresponding `<input>`, `<textarea>`, and `<select>` elements to ensure accessibility while preserving the minimalist visual design.
